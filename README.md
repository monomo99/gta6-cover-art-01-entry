Neon Shore Cover Studio — a multi-panel GTA-style cover maker: flip each panel, toggle the poster frame, add birds and halftone, tune the shot, and export a Vice City poster. Plain static files that load offline in a desktop browser, with three SIL OFL fonts and two sample photos made for make.fun.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080. `main.ts` (Node 22, standard library only) copies `app/` and `screenshots/` into the output and writes `dossier.json`, the summary the judge reads.
